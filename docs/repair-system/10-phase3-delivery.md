# 阶段 3：手工采购、收货与费用

已实现采购草稿、多条采购明细、订单截图、确认下单、取消及历史保留、分批收货、总部费用确认和替换验收。总部采购工作区沿用阶段 2 的 Ant Design 视觉规范；桌面同时查看原设施、订单图与采购明细，手机端可登记收货。

采购明细与原设施快照分别保存。金额使用 BigDecimal，前端预览使用整数分。已下单即可派单和接单，材料未全部到货时后端拒绝开工。采购截图、价格和费用仅总部可读；门店与工程师使用独立材料摘要，收货流水不含价格。

验收替换设备时，事务中只生成一份新资产、退役原资产并保留原型号和报修快照。费用未确认时返回 PENDING 和空总费用；明确填零才视作确认。
